# 因果视频注视联合修正方案

> 更新：2026-11-19。本文保留已实现联合修正方案的定义；任务顺序和真实验收以 [implementation_plan.md](implementation_plan.md) 为准。
> 状态：T1–T6、R1–R3、官方R4首轮及D1–D3均已完成验收。当前GRU残差/模板有效性实例尚未建立稳定—响应优势，D4无历史对照尚未执行。规则方法继续使用 `stag` 标识，联合模块为 `temporal_joint_refiner`。
> 当前方向复盘见 [idea_feasibility_review.md](idea_feasibility_review.md)：区分底座绝对精度与时序增量，讨论显式历史候选/效用监督及理想对照关系。该候选重构尚未实现，不覆盖现有模型或原实验结果。§8–§14的已完成作业无需重跑。

## 1. 最终目标与 motivation

在给定真实人物头框、只观察当前及过去 RGB 帧的条件下，判断历史注视证据是否仍然有效，联合修正当前注视热图和画内外状态：持续关注时抑制错误跳变，目标移动时保持正确跟随，转向新目标或画外时及时更新。

连续注视估计中，历史观察能够补充当前帧因模糊、遮挡或外观歧义而缺失的证据。但历史对应的目标会移动，相机可能改变画面位置，人物也可能主动转移注意力。把预测点的变化直接解释为真实切换，或把旧坐标直接平均到当前坐标，都不足以处理这些情况。

本方案研究的问题是：**当前人物与场景的视觉证据，能否帮助模型判断历史应被保留、更新还是释放，从而改善定位精度、状态判断、稳定性和响应之间的折中？**

协作场景中的应用链条是“逐人注视目标 → 共同关注或交流事件 → 团队活动感知”。当前首先解决第一环。VAT 上的逐人定位改善不能直接写成共同关注或协作效果改善；相关下游验证列入 R6。2026 年预印本 [Where are they looking in the operating room?](https://arxiv.org/html/2604.20574v1) 提供了注视热图服务团队交流、角色和阶段分析的具体应用锚点，其结果不作为本项目的实测结果。

## 2. 已有实验证据与本次调整

以下均为已跑的同一 ViT-B checkpoint、原始 VAT 真实头框及统一评测协议的结果，来自 [T5 完整六方法对照](results/t5_ema_ablation.md)；配置、事件分母和来源见对应 JSON 与 [RESULT_PROVENANCE.md](results/RESULT_PROVENANCE.md)。

| 方法 | AUC ↑ | L2 ↓ | In/Out AP ↑ | Jitter ↓ | 准确且稳定占比 ↑ | `gaze_shift` 响应率 ↑ |
|---|---:|---:|---:|---:|---:|---:|
| `single_frame` | 0.940182 | 0.098995 | 0.886801 | 0.016647 | 0.527531 | 0.582278 |
| `stag` | 0.936860 | 0.099197 | 0.886801 | 0.012135 | 0.581532 | 0.550633 |
| `ema_alpha_0p75` | 0.940120 | 0.098941 | 0.886801 | 0.014229 | 0.542534 | 0.569620 |

规则 STAG 提高了稳定性，但定位和画内切换响应未超过单帧。它相对部分强平滑 EMA 有响应补偿，尚未全面优于普通 EMA。T6 的实际案例用于解释这些先导结果，不用于选择新模块的参数；完整案例入口见 [t6_visualization.md](results/t6_visualization.md)。

原版 STAG 只修改热图，In/Out 分数原样输出，所以 AP 严格不变。它的三个标量分别是头框中心位移、预测画内外翻转、当前热图峰值相对历史峰值的位移。头框平移不能充分表示头部转向；In/Out 分数不是定位可信度；峰值跳变同时可能来自噪声、目标或相机运动、真实注意力转移。仅校准原有四个权重继续保留为简单对照，新主线增加当前视觉证据并联合修正两项输出。

## 3. 文献定位与创新假设

| 先行工作 | 已有机制 | 本方案需要进一步回答的问题 |
|---|---|---|
| [One Euro Filter，CHI 2012](https://gery.casiez.net/publications/CHI2012-casiez.pdf) | 随速度调整低通滤波，平衡抖动与延迟 | 如何区分视觉证据中的误跳和真实转移，而不只是根据位移改变平滑强度 |
| [FGFA，ICCV 2017](https://arxiv.org/html/1703.10025) | 先对齐跨帧特征，再加权聚合；原版使用前后文 | 如何在严格因果条件下使用历史目标对应，避免融合旧图像坐标 |
| [Cutie，CVPR 2024](https://arxiv.org/html/2310.12982) | 目标级记忆与当前帧匹配 | 注视目标允许主动改变，什么时候应释放过去目标的记忆 |
| [Chong et al.，CVPR 2020](https://arxiv.org/abs/2003.02501) | 场景与头部特征、ConvLSTM、热图及画内外输出 | 在普通循环记忆之外，选择性历史机制有多少额外收益 |
| [PDP，WACV 2023](https://arxiv.org/abs/2211.11062) | 空间及时间注意力，画内位置与画外状态的分布建模 | 联合输出本身已有先例，不能作为独立创新点 |
| [MTGS，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/1caf09c9f4e6b0150b06a07e77f2710c-Abstract-Conference.html) | 人物时序表示、多人交互与社会注视预测 | 不能以“已有工作没有视频或多人建模”为动机 |
| [Gaze-LLE，CVPR 2025](https://arxiv.org/abs/2412.09586) | 冻结视觉编码器与轻量人物条件解码 | 冻结骨干和轻量化是实现条件，不独立构成新贡献 |
| [ARGaze，2026 预印本](https://arxiv.org/html/2602.05132v1) | 第一人称因果历史热图、目标区域视觉模板、冻结骨干 | 历史热图和目标模板已有直接先例，须进一步证明历史失效判断的作用 |
| [EyeTAG，2026，页面注明 BMVC accepted](https://arxiv.org/abs/2610.00922) | 由历史预测差分构建因果运动信息，分析快速眼动偏差 | 因果轨迹与稳定/响应分析本身也已有研究；其三维方向任务与 VAT 分开讨论 |

因果推理、门控、记忆、模板和联合输出均不是单独的新颖性主张。本方案争取的贡献是：**针对第三人称人物条件注视，利用当前视觉证据判断历史目标证据的有效性，并用同底座、同信息条件的实验，验证对持续跟随和切换响应的额外作用。** 这是待检验的研究假设，论文贡献按实际完成的机制和结果收敛。

## 4. 输入、状态与输出

### 4.1 冻结单帧底座

- 统一复用 `gazelle_dinov3_vitb16_inout` 的 VAT checkpoint：`/home/fb/src/paper/gazelleV1/experiments/train_vat_sasa_ggsf/2026-03-12_19-24-13/epoch_7.pt`。
- DINOv3、GGSF、SASA 和原 decoder 全部冻结；单帧原始热图 `h_t` 与画内概率 `s_t` 保留为可复现基线。
- 当前帧 RGB 和当前真实头框是视觉输入。人物身份来自 T1 原始轨迹；不加入检测框、深度、未来帧或测试注视标签。
- 旧 `gazelle` 包只导入，不修改。新模块、特征提取包装和脚本全部放 `cscwd/code/`。

### 4.2 视觉证据与历史表示

| 量 | 来源与用途 |
|---|---|
| `F_t` | 当前 RGB 经冻结编码器得到的空间 patch 特征，用于当前场景和目标对应 |
| `q_t` | 当前真实头框内的特征汇聚，提供人物外观变化证据；头框本身不替代头部外观 |
| `h_t, s_t` | 当前单帧预测；保留分布形状和状态分数，不只保留 argmax |
| `m_{t-1}` | 同一人物过去预测及其视觉证据形成的紧凑状态 |
| `c_t` | 历史预测注视区域特征与当前 `F_t` 的对应证据；用于判断旧区域是否仍有视觉支持 |

历史注视区域从过去模型预测构造，不使用过去真实注视点建立测试记忆。这里的“目标表示”是预测区域的视觉表示，不等于已有目标实例 ID，也不假设有物体框或分割 mask。视觉对应是待检验的候选证据，最终输出仍是热图和状态，不预设模型能够完整区分所有变化原因。

R2 先在小样本上检查特征 shape 和存储，再确定最小冻结特征契约：记录特征层、空间网格、dtype 和索引映射。场景特征按唯一图像存储一次，由人物帧索引引用；避免按人物重复保存完整多层原始特征。原始 `heatmap / inout` 继续保留 float32 基准值。所有可学习投影属于新增模块，不缓存随训练更新的投影结果；历史容量在训练/验证配置中固定。

### 4.3 最小可训练路径与选择性历史

先实现一个普通的小型因果 GRU 联合头，接收同一套当前视觉证据、单帧预测和历史状态，输出修正热图 `H_t` 及修正画内概率 `S_t`。该版本建立训练和联合输出的基线，不把普通 GRU 命名为新机制。

R3 已实现 `HistoryValidityRefiner`：过去预测区域在原始冻结空间形成模板，与当前网格做 cosine correspondence；MLP 输出连续 validity 与 refresh，前者控制全部历史读入路径，后者控制模板写入。当前证据始终保留，两个零初始化残差头联合修正定位和状态，另有零初始化对应空间增益。具体公式、状态、诊断与消融语义见 [r3_mechanism_design.md](results/r3_mechanism_design.md)。

```text
Current RGB + GT head box
            |
      Frozen GazeSpot ----> h_t, s_t
            |
      Frozen patch features
            |
            +---- Current person/scene evidence
            |                  |
Past predicted target evidence -> Visual correspondence
                               |
                  History validity / causal update
                               |
                  Refined heatmap H_t + score S_t
                               |
                    Updated per-person memory
```

“保留 / 更新 / 释放”描述的是记忆控制的作用，不预设存在这三类真值标签，也不要求先实现三分类器。R1 的诊断决定 R3 需要区分的主要情形，R3 固定最小具体机制和消融后再训练。历史对应不确定时，应允许当前证据主导，而非把高相似度或高 In/Out 分数直接当作“目标正确”的标签。

## 5. 训练方式与因果约束

只训练新增时序模块及其轻量输入投影、热图和状态输出分支。冻结底座保持 `eval` 状态；特征缓存用于加快实验，不代表在线系统省去了每帧视觉编码。

- **定位监督**：使用当前帧真实画内落点构造热图，只在有效 GT 画内帧上计算定位损失。
- **状态监督**：使用当前帧有效画内外标签，在画内和画外人物帧上共同训练分类输出。
- **联合目标**：`L = L_heatmap + lambda_state * L_state`，首版使用 heatmap MSE 与状态 BCE。R2 一个 epoch smoke 已完成；当前 R4 采用 [r4_official_train_test_plan.md](r4_official_train_test_plan.md) 的单配置、seed 0、五个 epoch 计划，普通 GRU 与新机制从新模块随机初始化，在完整官方 train 上按同一预算训练，每轮完整 test 并按 AUC 选择 checkpoint。计划参数不作为既有实验数字填写。
- **历史输入**：训练和评测都由空状态开始，沿原始帧顺序形成预测历史；不用 GT 热图或 GT 状态替换历史预测，不以标签决定记忆重置。
- **重置边界**：人物轨迹开始和原始帧号不连续时重置；不同人物、不同轨迹不共享状态。
- **因果性**：视觉输入、归一化、注意力、状态更新和区域选择只依赖当前及过去帧；不采用居中窗口、双向时序或未来帧教师分支。序列切片的状态衔接方式在实现时固定，并核对与逐帧推理的一致性。

先使用已有逐帧标签训练主任务。GT 点位移只能定义切换代理事件；在没有目标身份或历史有效性真值时，不把代理事件直接等同于“应释放旧目标”的完备标签。

## 6. 指标与可以检验的收益

| 指标 | 新方案希望检验的作用 | 当前事实或评价条件 |
|---|---|---|
| AUC ↑ / L2 ↓ | 历史视觉证据能否纠正当前歧义、正确跟随目标 | 保持 GT 画内评测掩码，不按预测画内状态筛选定位样本 |
| In/Out AP ↑ | 联合状态头能否改善画内外样本的分数排序 | 原 STAG 不改分数，AP 严格不变；新模块能否提升须实测 |
| Jitter ↓ | 减少错误跳变 | 同报相同帧对 GT 位移，结合定位与响应解释 |
| 准确且稳定占比 ↑ | 既稳定又接近真实落点 | 沿用 T4 固定定义，避免把固定错误点计作有效稳定 |
| 代理切换响应率 ↑ / 延迟 ↓ | 减少过时历史造成的额外惯性 | `enter_frame / leave_frame / gaze_shift` 分开报告，保持分母、删失与配对比较 |
| 状态时序质量 | 减少错误画内外翻转，并响应真实状态转换 | AP、状态翻转和进出延迟分别评价；新增状态协议先在 R1 固定再比较 |

AP 使用连续分数，调整分类阈值不会提高 AP；统一的严格单调分数变换也不改变排序。提高 AP 不自动等于降低状态抖动或转换延迟。

按现有 T4 协议，原 STAG 的 `leave_frame` 响应严格不变，因为画外成功只依赖原始状态分数；`enter_frame` 和 `gaze_shift` 还要求定位正确，能够随热图变化。新方案修改 `S_t` 后，三类响应均可能变化。

目标是在可比定位质量下改善稳定性与响应，并检验 AP 是否同步改善。单个指标改善不代替完整对照，也不预先要求所有指标在每个配置上同时领先。

## 7. 数据划分、诊断与对照

### 数据使用

用户于 2026-11-18 明确指定后续仅使用官方 train/test，协议为 [r4_official_train_test_plan.md](r4_official_train_test_plan.md) 的 `r4_official_train_test_v1`。完整官方 train 的 132,563 人物帧训练新增模块；每个 epoch 后在完整 test 的 31,978 人物帧评测，按 test AUC 优先、L2 更低、AP 更高、较早 epoch 选择一轮整套指标。test 不参与梯度更新或模型历史输入，报告明确它参与 checkpoint 选择。

原 R1 分组与 R4 validation 报告保留历史标签；原 validation 的 34,201 帧纳入新一轮完整 train。冻结 GazeSpot checkpoint、当前真实框、原预测与原生空间特征合同不变。train 特征可直接复用；test 仅补特征，不重算已有原始预测。

VAT 的点和画内外标注没有完整目标实例 ID，位移阈值仍作为代理事件。人工诊断与机器事件记录保留各自语义。不同协议/种子的结果分开保存，论文说明按 test 选 epoch 的实际设置。

### 对照与消融

当前执行 `r4_official_train_test_v1`，先在官方 train/test 协议下比较两模型。T1–T6、R1/R2 和原 R4 validation 报告均保留；新配置、新训练与旧实验分开记录。

- 第一轮只训练普通因果 GRU 和新机制，各一组配置、seed 0、五个 epoch，共享冻结特征、当前视觉输入、标签和训练预算；保留单帧参考，完整报告每个 epoch。
- 每个 epoch 完整 test，AUC 降序、L2 升序、AP 降序、较早 epoch 选择；不应用旧 precision eligibility。所有标准/joint/state 指标与全部 epoch 完整报告，论文每行取自同一 checkpoint。
- 有信号后首项消融为关闭历史有效性控制、保留视觉输入与历史目标对应，按同预算重新训练。主要收益是状态阈值错误/进出响应时补 train 拟合的严格单调状态校准；主张历史本身有效时补同预算无历史联合头。
- 全部滤波器、门控网格、完整单输出矩阵、多项结构消融、多 seed 和 bootstrap 延后，不作为第一轮前置条件。单 seed 结果不称稳定复现；重复实验时先固定共同 seed 清单。

新 R4 已包含每轮 test 与选模，R5 汇总这批实际结果。普通 GRU 的 R2 一个 epoch smoke 不替代新 full-train 的同预算比较；未超过单帧或普通 GRU 的结果同样保留。
