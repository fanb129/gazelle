# 时序方向可行性、底座选择与理想实验关系

2026-11-19。D4尚未实现/执行。本文件是方向讨论和建议，不改变已运行协议、结果或既定选轮规则；理想结果均写为关系，不填未跑过的指标。

## 1. 判断

当前“单模板视觉对应＋GRU残差双头＋间接门控监督”的固定实现，尚未达到原先的稳定/响应目标，不宜继续只扩大模型或试调loss。尚未被否定的问题是：**在当前单帧已经很强时，如何只在历史确有帮助时使用它，并在注意力改变时及时退回当前证据。**

当前证据不能把失败归因于ViT-B或GazeSpot。同一个GazeSpot-B上，已有因果EMA能改善稳定性和L2；学习型模块未跨过这个简单对照的折中。D4仍是一个有价值的最小分叉实验，用于区分新增当前帧解码能力与历史本身的收益。

- T5证明预测历史可提供一定的连续性收益，但强平滑会损失切换响应。目标应是改善这个折中。
- D1显示状态输出替换主导原新机制的准确稳定损失；D2预声明train校准只能补回部分，不能替代时序机制。
- D3与原同epoch相比，两模型五轮AP均下降、L2均增加，准确稳定均只有epoch 4增加。不能只用“原选epoch 5→新选epoch 3”的改善证明loss有效。
- 目前AP的部分改善还没有通过D4归因：它可能来自新增当前视觉修正头，也可能部分依赖历史。
- 五轮不是充分收敛的证明；但现有同轮和简单对照也没有支持“只要训练更久就会好”。若未来延长预算，比较方法应共享新预算。

## 3. 结构上的可检验假设

下列是代码事实及其可能影响，不是已证实的失败成因。

1. 当前空间网格仍保留；heatmap残差由hidden条件化的通道读出与对应图产生，并未完全丢掉空间。但没有显式形成“对齐后的历史热图候选”与当前热图进行选择。
2. 历史目标是过去预测区域的单个加权平均描述符，多峰、背景和相似目标可能混合。目标外观仍匹配，不等于人物仍关注它。
3. 同一个validity同时控制hidden、目标对应和旧In/Out；目标模板与状态记忆的有效性不一定同步。当前模板在预测画外时也会写入由热图产生的区域表示。
4. validity/refresh主要靠最终MSE/BCE间接学习；门值出现不等于学到了何时历史更有用。D1聚合也未显示清晰的事件低门释放形态。
5. 新模块用的是冻结backbone末层原生特征，不是完整GazeSpot经过GGSF/SASA与人物条件decoder的中间表示。更大底座的优势未必通过现有接口充分传入。

## 4. ViT-B、ViT-L与Gazelle/GazeSpot是两条选择轴

ViT-B/L是编码器规模；Gazelle/GazeSpot是模型设计、特征与checkpoint体系。Gazelle为原Gaze-LLE官方仓库，使用DINOv2；本地GazeSpot使用DINOv3等扩展。关闭本地GGSF/SASA得到的DINOv3基线，不能直接称为官方Gazelle。

[Gaze-LLE官方论文表3](https://arxiv.org/html/2412.09586v2)报告VAT的B为AUC/L2/AP 0.933/0.107/0.897，L为0.937/0.103/0.903；[官方仓库](https://github.com/fkryan/gazelle)提供对应模型。它们是论文结果，不是本项目CSCWD流水线的新复现。尤其Gazelle-B报告AP高于当前GazeSpot-B，不能把Gazelle当成所有指标都更弱的底座。

本地[GazeSpot源稿主表](/Users/fanb/src/gazelle/icassp2027/2026ACMMM/main.tex:519)记录ViT-L 0.944/0.092/0.912；CSCWD尚无该L checkpoint的同协议完整时序评测，不能把稿件记录当成本轮新基线。

| 选择 | 适合回答的问题 | 当前建议 |
|---|---|---|
| 现有GazeSpot-B | 当前模块能否利用已有历史信息 | 保留现有缓存，完成最小可行性判定 |
| 官方Gazelle-B | 方法在公开、独立底座上是否也有效 | 优先第二底座；若强调独立复现，可在机制有信号后作为论文主底座 |
| GazeSpot-L或Gazelle-L | 更高绝对精度与跨规模效果 | 不先重跑整套；如需了解L，先做L单帧及相同时间指标 |

ViT-L可能改善语义与对应，但同分辨率/patch设置下不会自动增加头框所占patch数，也不会直接修复模板混合、门控监督和状态耦合。官方Gaze-LLE本身也展示过：直接换强encoder到不适配的解码架构并不保证更好。B/L的本项目速度倍数尚未实测，不给估计数。

正确的跨底座证据是分别比较“B＋模块 vs B单帧”和“L＋模块 vs L单帧”。“L＋模块优于B单帧”不能单独证明时序贡献。官方Gazelle必须独立复现/缓存；L也需要对应的新预测和特征，不能混用B缓存。

## 5. 更值得检验的方法重构

将当前单帧预测作为可靠锚点，明确构造由当前/过去特征对应得到的历史候选，学习**历史候选对当前帧任务是否有帮助**。

- 当前候选：冻结单帧预测。
- 历史候选：仅由过去预测和当前/过去视觉对应得到，保留必要空间结构或多个区域表示。
- 训练监督：仅在train用当前GT比较候选损失，构造历史效用信号；不把GT输入模型或历史。
- 推理选择：只根据RGB、真实头框、当前预测和自身过去状态，决定当前主导、历史补充或释放历史。
- 定位记忆与画内外状态分别控制，避免一个门同时决定不同语义的历史有效性。

可以先固定原In/Out，集中解决画内定位稳定/切换；此时AP、状态错帧/翻转和leave响应保持原值，论文贡献相应收缩，不声称联合状态改善。若空间历史明确有效，再独立加入状态记忆与监督。

简单门控、因果记忆和模板已有先例，例如[MTGS](https://github.com/idiap/MTGS)和第一人称[ARGaze](https://arxiv.org/html/2602.05132v1)。上述重构仍是待检验假设；创新点应落在第三人称人物条件下的历史效用判断、明确机制及其额外收益，不能预称首次。

## 6. 理想实验结果是关系，不是预填数字

最理想的证据是：**定位质量可比时，持续关注更准确稳定，代理切换时保持或改善响应，并超过强平滑与普通时序模型。** 不要求所有指标同时第一。

| 对照 | 理想结果应说明什么 |
|---|---|
| 同checkpoint单帧 | 准确稳定提高，定位质量保持，切换响应保持或更好 |
| D4当前帧头 | 核心时序收益超过只增加当前帧修正能力；声称历史改善AP时，AP也须超过它 |
| 同当前输出上的固定EMA | 同等响应下更稳定，或同等稳定下响应更快；不只与弱平滑配置比较 |
| 普通GRU | 显式历史选择提供额外作用，而非仅“加了一个时序层” |
| 保留对应、关闭选择门 | 完整机制的相关收益减弱，支持门控的必要性 |
| 第二底座 | 相对各自单帧的增量方向保持，不混合绝对基线差异 |

主表保留AUC/L2/AP，另画准确稳定—响应折中并同时列失响应数/共同事件延迟；不通过只保留容易响应的事件降低平均延迟。AP排序、状态错误翻转、进出响应是不同指标。若只做空间修正，AP不升可以接受；目标与主张要一致。

分组可报告固定协议的稳定段和GT位移代理事件，以及人工核实的案例；VAT没有完整目标ID，不能把坐标变化全称为真实注意力转移。协作/共同关注收益仍需有对应真值的下游验证，逐人稳定性本身只支持应用动机。

## 7. 最小行动顺序与分叉

1. 保留现有GazeSpot-B，先完成既定D4一个模型：原逐帧目标、五轮、seed 0。它用于解释原AP收益，不自动修复当前机制。
2. 若要重构，先在train做当前候选/因果历史候选的效用分析：当前独有正确、历史独有纠正、两者均正确、两者均错，并分稳定/变化组。GT选择只作候选集合的oracle参考，不当作部署模型或所有视频信息的理论上限。
3. 有可利用的历史补救空间时，再实现一版候选选择机制；若机会很少或选择所需证据不足，调整目标或停止当前实例，不继续扩大同一GRU。
4. 机制出现相对强对照的增量后，再做最少消融和官方Gazelle验证；ViT-L作为后续规模/精度扩展，不作为当前失败的默认修补。

D4若已接近原GRU/HV，则原AP增益不需要历史；GRU若领先D4而HV不领先GRU，则普通历史有用、当前有效性机制需要重构；只有HV超过这些对照并改善稳定/响应，才值得扩展当前机制。五轮预算、逐epoch test和AUC选整轮的用户约定保持，折中图不替换已声明的主行。
