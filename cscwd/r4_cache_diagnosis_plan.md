# R4 缓存贡献与历史控制诊断

版本：`r4_cache_diagnosis_v1`，2026-11-18。此任务接在已验收的官方train/test首轮之后，用已保存输出决定下一项训练调整。原 `r4_official_train_test_v1` 计划、选中epoch和源报告保持。

## 输入与执行范围

读取 `r4_official_comparison.json` 引用的两份训练报告和各自AUC选中的test缓存；当前真实首轮均为epoch 5。原始单帧来源为 `t2_single_frame_cache.json`。核对报告、所选checkpoint、预测/诊断index和文件SHA，按人物轨迹、原始帧和source行对齐。

只在CPU读取预测坐标、分数、已有门控/对应控制量及离线GT。大热图文件进行来源SHA核对，checkpoint只作文件核对；不加载模型、不前向、不训练，也不读取90GB train视觉特征或新test视觉特征。GT、未来侧事件邻域只用于离线计分/分组，不产生新模型预测。

## 四种交叉组合

| 标识 | 坐标 | In/Out分数 |
|---|---|---|
| M00 | 原始单帧 | 原始单帧 |
| M10 | 时序修正后 | 原始单帧 |
| M01 | 原始单帧 | 时序修正后 |
| M11 | 时序修正后 | 时序修正后 |

每种模型分别计算四组合。固定旧 `TemporalConfig`：稳定阈值0.02，定位半径0.10，GT位移事件阈值0.15，连续成功3帧，响应上限30帧，状态判断严格 `score>0.5`。完整报告L2/AP、准确稳定、Jitter、joint响应和独立state指标。坐标不能唯一确定热图，因此本诊断不重新计算AUC。

M00和M11必须重现既有单帧/所选模型的L2/AP及全部时序/状态摘要；各组合分母与原轨迹范围保持。逐轨迹/事件明细写服务器详情目录，小报告保留汇总。

以准确稳定窗口数为M值，给出精确数值分解：

- 坐标项：M10−M00。
- 状态分数项：M01−M00。
- 交互项：M11−M10−M01+M00。
- 三项之和等于总变化M11−M00。

另对两种替换顺序取平均，给出对称贡献（Shapley形式）；它是输出替换的数值分解。对原本成功而修正后失败、及相反情况，按“坐标不稳 / 定位不准 / 窗口内预测画外”三个条件的失败组合统计互斥计数，保留多条件同时失败，不强行指认唯一原因。四组合不替代重新训练的结构/单输出消融。

## 历史控制与对应汇总

核对 `source_global_indices` 和原帧映射后，按全部帧、历史可用/不可用、GT画内/画外、相邻GT稳定画内帧端点、三类GT_proxy事件邻域汇总。事件邻域固定原帧号前后3帧，同连续段内截断，不跨人物/缺口，各组允许重叠。

记录八列控制量的均值/标准差/分位数；低/高门阈值固定0.1/0.9。validity另在历史可用帧上单独汇总。历史可用帧给对应坐标到原预测/修正预测的距离；到GT距离仅在GT画内计分，不当成目标身份匹配准确率。记录门值与坐标/分数修正幅度的Pearson关联，常量/不足两样本为null；相关性不作为机制因果结论。
