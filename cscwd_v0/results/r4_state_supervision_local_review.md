准确稳定分母为19,796窗口；gaze_shift响应分母为158个可评估事件。下表为本轮按原规则选中的完整结果。

新机制相对单帧AUC/AP略高、状态错帧少73，但L2更大、准确稳定少303窗口、错误翻转多125次，gaze_shift少3个、joint enter少8个（161→153）。joint leave为91→107；91个共同响应事件平均快0.945帧，同时gaze_shift失去3个原可响应事件，不能把出画改善扩展成所有切换改善。

相对本轮GRU，新机制的L2/AP和状态错帧略好，但准确稳定少63窗口、AUC更低，错误翻转只少1次；joint enter少4个、leave/gaze各多1个。这仍是指标折中。

## 关键比较：相同epoch

如果只比较原先选中的新机制epoch 5与D3 epoch 3，会看到准确稳定 **9,964→10,140（+176）**、错误翻转 **798→717**。但选择的训练轮次同时改变，不能把这两个整行的差值直接当作新loss的贡献。

同一模型、同一epoch对比更能说明本次训练改动：

- GRU：**−96 / −53 / −77 / +102 / −35**。
- 新机制：**−69 / −36 / −92 / +79 / −46**。

两模型都只有epoch 4稳定窗口增加；**十个同轮比较中AP全部下降，L2全部增加**。在本次单seed固定配置下，尚无一致训练收益。epoch 4新机制有较好折中：AUC 0.940424、L2 0.099050、AP 0.892620、准确稳定51.8691%、gaze_shift 92/158，但按预声明AUC规则未选中；它可作为全轮分析，不能临时替换主结果或抽取最好列。

选中epoch 3的新机制，加权stable项约0.000214、transition项约0.009640，日志数值相差约45倍。这说明两项数值尺度不同，不等价于梯度比例，也不能据此预判调整权重就会成功。本轮不继续追加lambda扫描或D3校准。

## 下一步：R4-D4最小无历史对照

下一步收束为 **一个当前帧联合修正头**：保留与普通GRU相同的当前视觉特征、原预测、真实头框和输出结构，每帧清空预测历史；从头五轮、seed 0，使用原逐帧heatmap MSE/状态BCE，不加入D3时序loss或D2校准，沿用完整train/每epoch test/AUC选整轮。

这一个对照直接回答：原首轮的AP增益主要来自新增当前视觉修正，还是依赖历史？若无历史已相当或更好，就调整或简化当前历史方案；若历史显示明确优势，再做最小validity读门对照。结构/有效参数和重置约定将在实现前写清，不把清空状态等同于所有参数都有相同作用。
