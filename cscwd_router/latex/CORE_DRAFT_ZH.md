# 面向注视目标估计的人物条件化稀疏计算：中文核心稿

## 一句话定位

在共享视觉编码器的中间层，联合场景、头部外观和相对几何预测注视相关区域，让有限的深层计算优先服务于被查询人物，研究定位精度与实际推理成本的权衡。

## 动机与问题

以往许多注视目标估计方法分别编码场景、头部及辅助线索。GazeLLE采用冻结视觉基础模型和轻量人物条件解码器，简化了结构与任务训练；但编码器在推理时仍对全图token执行全部层。**减少可训练参数之后，如何进一步减少实际执行的视觉计算？** [GazeLLE原文](https://openaccess.thecvf.com/content/CVPR2025/html/Ryan_Gaze-LLE_Gaze_Target_Estimation_via_Large-Scale_Learned_Encoders_CVPR_2025_paper.html)

Mi等人的ECCV工作利用“头部外观＋眼位置→MLP方向预测→平滑FOV先验”，结合对象语义和DINOv3多层特征辅助定位，并使用离线YOLO/SAM对象掩码。从其结构看，人物几何信息用于引导特征融合，尚未用于减少主干深层token执行；这是本文关注的计算缺口，不能据此断言其实际延迟更高。[原文§3.2–3.4、§4.1](https://arxiv.org/html/2606.29334v1)

由此提出问题：**人物条件能否在编码器中途指导“继续计算哪些位置”，使注视相关区域得到深层处理，同时减少其余位置的计算？** 这将人物线索的作用从辅助定位扩展到计算分配。本文实现独立的条件路由，没有直接复用Mi的方向/FOV模块。

## 方法与贡献

```text
RGB → 共享 dense prefix → 场景特征＋头部区域池化特征＋头框相对几何
    → 人物 support → 多人 max-union → 固定预算 Top-K
    → sparse suffix → 未选位置以中间特征回填 → 多层解码 → 热图 / in-out
```

Router复用共享中间特征，无需额外头部图像编码器。其输出是受目标覆盖监督的空间support；推理只输入RGB与真实头框。当前实现没有显式方向向量预测，也不把“浅层特征等于注视方向”作为前提。头部和少量全局位置在总预算内优先保留，多人共用一条稀疏后段。

核心贡献集中于：**场景、头部外观和相对几何联合条件化的计算选择，以及固定预算下的共享稀疏执行与完整网格回填。** DINOv3和多层表示是沿用的高精度基础配置；不作为新的贡献，也不重复主张ICASSP中的多层融合或软门控贡献。

## 实验组织

采用GazeFollow、VAT，覆盖ViT-B/L；seed0，仅官方train/test，每轮test后按GF Min L2、VAT L2选单一checkpoint。VAT从相应GF Router迁移，最终逐帧test；GF-L来源保留实际support3＋decoder4轮的收口记录。准确率标注FP32，效率标注FP16。

## 结论工作稿

本文将人物相关线索用于视觉编码器的深层计算分配，在保留竞争力定位表现的同时获得批量推理收益。现有四组batch8相对同权重routed K100加速约1.25–1.31倍；VAT-L相对官方GazeLLE-L有1.065倍的小幅速度收益。同权重K100单次精度参考和条件化消融用于补足质量保持与人物条件增益的证据；结论按具体指标、batch和对照分别陈述。
