## GOO-real OOD Evaluation

Source: `rebuttal/results/p0/gooreal_eval.json`

Dataset path: `/newhome/fb/dataset/gooreal_data`

JSON path: `/newhome/fb/dataset/gooreal_data/gooreal_test_preprocessed.json`

Sample count: 2146 images, 2146 heads

| Dataset | Method | AUC ↑ | Avg L2 ↓ | Min L2 ↓ |
| --- | --- | ---: | ---: | ---: |
| GOO-real | Baseline (DINOv3 last-layer) | 0.8583 | 0.1997 | 0.1997 |
| GOO-real | GazeSpot | 0.8833 | 0.1761 | 0.1761 |

Rebuttal takeaways:

- GazeSpot improves GOO-real AUC by 2.49 percentage points.
- GazeSpot reduces GOO-real L2 by 0.0236.
- `Avg L2` and `Min L2` are identical here because the current preprocessed
  GOO-real file has one gaze target per head.

## Complexity and Runtime

Source: `rebuttal/results/p0/complexity_latency.json`

Device: NVIDIA GeForce RTX 3090

Benchmark configuration: batch size 1, 50 warmup iterations, 200 measured
iterations, CUDA synchronization enabled

| Method | Input | Trainable Params ↓ | Total Params ↓ | MACs/FLOPs ↓ | Latency ms/img ↓ | FPS ↑ | Device |
| --- | --- | ---: | ---: | --- | ---: | ---: | --- |
| Baseline (GF) | 448x448 | 2,826,752 | 88,496,384 | 53.61G MACs / 107.22G FLOPs | 18.3657 | 54.4495 | NVIDIA GeForce RTX 3090 |
| GazeSpot (GF) | 512x512 | 3,515,394 | 89,185,026 | 70.54G MACs / 141.08G FLOPs | 22.8200 | 43.8212 | NVIDIA GeForce RTX 3090 |
| Baseline (VAT) | 448x448 | 2,860,033 | 88,529,665 | 53.61G MACs / 107.22G FLOPs | 18.2932 | 54.6651 | NVIDIA GeForce RTX 3090 |
| GazeSpot (VAT) | 512x512 | 3,548,675 | 89,218,307 | 70.54G MACs / 141.08G FLOPs | 23.1668 | 43.1653 | NVIDIA GeForce RTX 3090 |

Rebuttal takeaways:

- Parameter reporting is now transparent: both trainable parameters and total
  parameters including the frozen VFM are shown.
- GazeSpot adds about 0.69M trainable parameters over the baseline.
- GazeSpot is slower because it uses 512x512 input and extra modules, but remains
  batch-1 real-time on RTX 3090 at about 43 FPS.

## Recommended Rebuttal Use

Use the following P0 evidence in the rebuttal:

- GOO-real OOD: include the two-row GOO-real table because GazeSpot improves both
  AUC and L2 on 2146 real-domain samples.
- Robustness: use `test_crowd_gt4` as the main head-box noise table because it
  matches the hardest crowd setting and shows consistent gains on AUC, L2, and
  In/Out AP under all jitter levels.
- Complexity: include the RTX 3090 table with `Trainable Params` and
  `Total Params`; explicitly state that FLOPs are THOP-profiled and reported with
  measured latency/FPS.

Avoid over-claiming:

- Do not claim GazeSpot improves In/Out AP on every crowd subset; `eq4` and
  `test_crowd_4` show lower In/Out AP than the baseline.
- Do not describe the CPU smoke test as deployment latency; only the
  `complexity_latency.json` RTX 3090 output should be used for latency/FPS.
